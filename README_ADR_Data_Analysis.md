# Adverse Drug Reaction (ADR) Data Analysis

## Project overview
This project explores a synthetic pharmacovigilance-style dataset containing reported symptoms, suspected medicines, concomitant medicines, report dates, onset times, seriousness, outcomes, dechallenge/rechallenge information, and illustrative causality categories.

## Workbook sheets
- Dashboard — summary indicators and charts.
- ADR Case Data — 120 synthetic case reports.
- Drug Analysis — reports by suspected drug and serious reports.
- Symptom Analysis — frequency of reported symptoms.
- Monthly Reports — monthly report counts.
- Seriousness — serious versus non-serious reports.
- Causality Summary — illustrative causality-category counts.
- Notes & Methodology — definitions and limitations.

## Important interpretation
All records are synthetic and for educational purposes. Report frequency is not ADR incidence or proof of causation. A medicine with more reports is not necessarily more dangerous; exposure denominators, reporting bias, patient factors, concomitant medicines, dose, timing, alternative causes and clinical review matter. The causality labels are simulated, not real clinical assessments. Do not use this workbook for diagnosis, treatment or actual pharmacovigilance signal detection.
